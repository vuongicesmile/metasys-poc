# User Email Notification Guide

Frontend tĩnh giúp đọc runbook Dataverse/Power Automate theo từng bước. Trang
không gọi Dataverse, Outlook hoặc API bên ngoài; checklist chỉ dùng localStorage.

```powershell
cd .\docs\interactive\user-email-notification-guide
npm test
npm run test:browser
npm start
```

Mặc định mở tại `http://127.0.0.1:5421/`. Có thể mở trực tiếp `index.html` bằng
`file://` nếu không cần local server.
